# Berries & You — Frontend (React + Tailwind)

## Run
    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in /dist

## Customise
- `src/data.js` — menu, prices, plans, FAQs, WhatsApp number (everything in one place)
- Real photos: put images in `/public` and set `img: '/name.jpg'` on a smoothie in `data.js`
- Logo: `src/Logo.jsx` (swap the SVG for your real logo, or use <img src="/logo.png" />)
- Colours: `tailwind.config.js` -> `colors`
